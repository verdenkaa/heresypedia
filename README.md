> Веб-каталог для настольной игры Warhammer: The Horus Heresy. Позволяет просматривать юнитов, их характеристики, вооружение и специальные правила. Проект демонстрирует навыки работы с Flask, SQLAlchemy и реляционными базами данных.

 **Демо**: [heresypedia.vercel.app](https://heresypedia.vercel.app/)

---

## Особенности

- **Backend**: Flask с серверным рендерингом шаблонов (Jinja2)
- **База данных**: SQLite + SQLAlchemy ORM с проектированием схемы из 4 сущностей
- **Функционал**: Фильтрация по типу юнита (HQ/Elites/Troops), поиск, детализация с отображением вооружения и правил
- **Деплой**: Настроен для работы на Vercel (serverless-совместимый запуск)
- **Лицензия**: Некоммерческий фан-проект, все права принадлежат © Games Workshop
